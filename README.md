# TEMPO

TypeScript + HTML/CSS + Vite の軽量な時計・タイマー・ストップウォッチ。

```sh
npm install
npm run dev
```

`npm run build` で型チェックと本番ビルド。`dist/` を静的ホスティングで公開できます。

- 大きな24時間表示、端末のローカル時刻、全画面表示
- 時計タブの「世界時計を表示」をチェックすると、メイン都市と6都市の世界時計を表示。チェック状態と都市選択をブラウザに保存
- タイマーのプリセット／分秒指定／一時停止と再開。終了時刻を保存しリロード後も復元
- ストップウォッチとラップ（ページを再読み込みするとリセット）
- ユーザーが許可した場合のシステム通知と通知音

通知は HTTPS または localhost で利用してください。通知許可はボタン操作で要求します。Service Worker は通知表示とクリック時のアプリ表示を担当し、常駐タイマーとしては使用しません。タブを閉じた後の予約通知は非対応です。バックグラウンドの処理制限・スリープにより通知が遅れる場合があります。復帰時には終了時刻から残り時間を再計算します。閉じた後の通知には別途 Push 配信サーバーなどの設計が必要です。通知音はタイマー開始の操作で準備しますがブラウザ・OSの制限を受けます。

タイマーは実時刻との差分、ストップウォッチは performance.now() の差分で計測します。ストップウォッチのスリープ中の計測はブラウザとOSにより異なります。時計は端末の時計に従い、外部時刻サーバーと同期しません。外部フォントやランタイムUIライブラリ、サーバー、DBは使用しません。

`npm test` でバックグラウンド相当の遅延、一時停止・再開、保存状態からの復元、ストップウォッチの計測を検証します。システム通知の実表示は対応ブラウザで確認してください。

## 終了音の設定

「設定」タブでデフォルト音（同梱の `alert.mp3`）とインポートしたMP3を切り替えられます。「MP3をインポート」で20MB以下のファイルを選ぶと、再生可能か確認してから選択します。「音を試す」で試聴、「取り込んだ音を削除」でデフォルトに戻せます。インポート枠は1つで、次の取り込みで置き換わります。

音声ファイル・音の選択・終了音のオン／オフはIndexedDBに保存します。外部へのアップロードはありません。同じブラウザ・同じサイトで復元されますが、サイトデータの削除で消えます。保存を利用できない環境では画面を開いている間のみ利用できます。

PCでは設定を独立したタブに移し、画面の高さに合わせて時間表示を調整します。ラップ記録は一覧内をスクロールできます。小さいウィンドウや拡大表示では、操作項目を隠さずスクロールで利用できます。

## PWAとして利用する

`npm run build` でmanifest、アイコン、オフライン用Service Workerを含む `dist/` が生成されます。HTTPSの公開先へ `dist/` の中身をアップロードしてください。ローカル確認はビルド後に `npm run preview` を実行し、localhostで開きます。

公開先をオンラインで一度開き、Service Workerによる保存が完了すると、時計画面・スタイル・JavaScript・標準アラームをオフラインでも利用できます。ブラウザのサイトデータを削除した場合は再度オンラインで開いてください。開発サーバーではオフライン用ファイルを保存しません。

macOS Sonoma以降のSafariでは「ファイル → Dockに追加」で登録できます。更新は再ビルドした `dist/` を公開します。新しい版のダウンロード後、既存のアプリウィンドウと同じサイトのタブをすべて閉じて再度開くと反映されます。実行中のタイマーを自動リロードで中断しません。アプリを閉じた状態の終了通知は非対応です。
